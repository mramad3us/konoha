# Controls

Keys are read by physical position. The table shows QWERTY / AZERTY where they differ;
the in-game help (`?` or F1) shows the labels of your own keyboard.

## Moving

Movement is relative to the screen: "up" walks up the screen.

| Keys | Action |
|---|---|
| Arrows, Numpad 2 4 6 8, H J K L | Move down-screen, left, right, up |
| Numpad 7 9 1 3, Y U B N | Move diagonally (up-left, up-right, down-left, down-right) |
| Click a tile | Walk there (stops if you're spotted) |
| Space, `.`, Numpad 5 | Wait a second (in melee: Guard) |
| Shift + Space | Pass time (minutes, an hour, until night or morning) |
| C | Sneak (shows enemy sight lines) |
| R | Run (costs stamina, noisy) |
| D | Chakra Dash (once learned) |

## Fighting

| QWERTY | AZERTY | Action |
|---|---|---|
| Q | A | Strike — beats Break, loses to Guard |
| W | Z | Break — beats Guard (staggers), loses to Strike |
| E | E | Guard — beats Strike (parry), loses to Break; covers you from everyone |
| Tab | Tab | Next adjacent target |
| T | T | Throw (Tab cycles targets, T switches kunai/shuriken, F throws) |
| G | G | Kawarimi (costs chakra; 1 tempo while engaged) |
| X | X | Draw / sheathe kunai (lethal or subduing) |
| V | V | Bandage yourself |
| 1 … = | & é " ' ( § è ! ç à ) - | Hand signs: Rat, Ox, Tiger, Hare, Dragon, Snake, Horse, Ram, Monkey, Bird, Dog, Boar |

Walking into an enemy strikes. Striking an unaware enemy from behind is a takedown.

## Everything else

| Key | Action |
|---|---|
| F, Enter | Interact: doors, people, bodies, facilities |
| Right-click | Actions for whatever you click |
| Z (QWERTY) / W (AZERTY) | Squad orders: follow & engage → defend only → hold |
| P | Character |
| O | Journal |
| I | Pack |
| ? or F1 | Controls |
| Page Up / Page Down, mouse wheel | Zoom |
| Esc | Pause, save, settings |
